# Features

| Feature ID | Brief description |
| --- | --- |
| `GEOGRAPHY.RU_REGIONS` | Complete selectable first-order administrative region catalog and map coverage for Russia. |
| `GEOGRAPHY.BY_REGIONS` | Complete selectable first-order oblast catalog and map coverage for Belarus, including Minsk city. |
| `GEOGRAPHY.PILOT_DISTRICTS` | Complete pilot district catalogs and boundary coverage for Smolensk and Vitebsk Oblasts. |
| `GEOGRAPHY.MULTI_REGION` | Compare candidate sites and investigations across multiple administrative regions. |
| `MAP.BASEMAP` | Map backgrounds and validated reference boundaries with traceable geography. |
| `SOURCES.CATALOG` | Discover source capabilities and their country, coverage, and availability. |
| `SOURCES.SYNTHETIC` | Controlled fixture data for repeatable product and agent scenarios. |
| `SOURCES.PUBLIC_WEB_RU` | Approved Russian public websites, newspapers, and Internet publication evidence. |
| `SOURCES.PUBLIC_WEB_BY` | Approved Belarusian public websites, newspapers, and Internet publication evidence. |
| `SOURCES.SATURN_RU` | Controlled Russian FGIS Saturn source with independently verified access and evidence types. |
| `SOURCES.GEOSPATIAL` | Additional approved land-cover, crop, forage, and geospatial datasets. |
| `DATA.PROVENANCE` | Source attribution, evidence version, coverage, and uncertainty tracking. |
| `DATA.PERSISTENCE` | Durable completed investigations, geometries, and seasonal plans. |
| `DATA.CACHE` | Bounded reuse of compatible source data and analysis artifacts. |
| `JOBS.EXECUTION` | Execute and inspect bounded investigation jobs. |
| `JOBS.RECOVERY` | Resume, retry, cancel, and recover long-running jobs safely. |
| `ENGINE.TYPED_CAPABILITIES` | Typed source/analyzer registration, inputs, outputs, and error contracts. |
| `ENGINE.DAG_EXECUTION` | Validate and execute dependent geospatial analysis operations. |
| `AGENT.DETERMINISTIC_REPLAN` | Reconsider plans based on new permitted evidence and explicit limits. |
| `AGENT.EVIDENCE_TRACE` | Explain and compare investigation choices and replan outcomes. |
| `AGENT.LLM_PLANNING` | Optional validated LLM plan generation using registered tools. |
| `FORAGE.FLOWERING_WINDOWS` | Model plant flowering windows and possible nectar/pollen opportunities. |
| `FORAGE.CONTINUITY` | Compare candidate locations for seasonal forage gaps and overlaps. |
| `WEATHER.PHENOLOGY` | Estimate weather-dependent flowering shifts with explicit uncertainty. |
| `ECOLOGY.RESTRICTIONS` | Apply verified ecological/legal restrictions within their actual scope. |
| `ECOLOGY.HABITATS` | Compare sensitive habitat evidence and potential pollinator conflicts. |
| `ECOLOGY.ALTERNATIVES` | Find and explain alternatives to constrained or uncertain apiary sites. |
| `AGRICULTURE.NOTICES` | Distinguish published treatment notices, reported activity, and unknowns. |
| `COLONIES.WELLBEING` | Represent user-provided bee-family constraints during site decisions. |
| `PLANNING.SEASONAL_STOPS` | Propose an ordered sequence of apiary stops and time windows. |
| `PLANNING.ROUTE_ALTERNATIVES` | Compare constrained seasonal routes and relocation trade-offs. |
| `WEB.MAP_TIMELINE` | Visualize countries, regions, sites, seasonal schedules, and explanations. |
| `WEB.INVESTIGATIONS` | Launch investigations and reopen prior results from the browser. |
| `RESEARCH.COMPARISONS` | Compare ecological evidence and uncertainty across territories or seasons. |
| `RESEARCH.FIELD_OBSERVATIONS` | Record methodological field observations of pollinators and habitats. |
| `RESEARCH.LONGITUDINAL` | Analyze and preserve repeated monitoring results across years. |
